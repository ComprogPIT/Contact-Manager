# Contact Manager

A simple GUI-based contact management system built with Python and Tkinter.

## Features
- Add a new contact
- Update an existing contact
- Delete a contact
- Search for a contact
- View all contacts in a list
- Saves all contacts in a text file (contacts.txt)

## How to Run
1. Make sure Python is installed
2. Run the program by typing: python contact_manager.py

## Project Info
- Language: Python
- GUI Library: Tkinter
- File Storage: contacts.txt (pipe-separated format)
